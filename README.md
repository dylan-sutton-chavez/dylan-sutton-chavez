---

### Systems

**interpreter** 

A Rust SDK that makes building a runtime easy. You define a token table, a few rules and the natives your programs call. It brings a state-machine lexer, a single-pass parser that writes SSA bytecode with no AST, and a tiered register VM with NaN-boxed values, inline caches, a mark-sweep GC and snapshots.

- Source: [dylan-sutton-chavez/interpreter](https://github.com/dylan-sutton-chavez/interpreter)
